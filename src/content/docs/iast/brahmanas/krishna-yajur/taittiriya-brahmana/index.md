# Taittirīya brāhmaṇam — Sūcī

Taittirīyabrāhmaṇam has three āṣṭakas and twenty-eight prapāṭhakas. Prapāṭhakas 3.10–3.12 of the third āṣṭaka are traditionally the **Kāṭhakam** (Kāṭhaka). Select an āṣṭaka to read.
