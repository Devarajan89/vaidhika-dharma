# तैत्तिरीय ब्राह्मणम् — सूची

तैत्तिरीयब्राह्मणस्य त्रीणि अष्टकानि, अष्टाविंशतिः प्रपाठकाः। तृतीयाष्टके दशमाद्वादशप्रपाठकाः परम्परया **काठकम्** इति प्रसिद्धाः। अष्टकं चिनुत।
