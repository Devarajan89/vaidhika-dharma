# द्वितीयम् आरण्यकम्, षष्ठोऽध्यायः — ऐतरेयोपनिषत् 3

अयम् अध्यायः **ऐतरेयोपनिषदः** अंशः (द्वितीयम् आरण्यकम्, चतुर्थषष्ठाध्यायाः)। पाठः उपनिषत्संग्रहे प्रकाशितः, अतः अत्र न द्विरुत्पाद्यते।
